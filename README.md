# Face Object Detection and Recognition

## Project Goal
Train an object detection and recognition model on a custom dataset of my own images using YOLO (Ultralytics).

## Dataset
- At least 500 photos of myself, taken in different lighting, angles, and backgrounds
- Stored in Google Drive: <https://drive.google.com/drive/folders/1zSlnSDi89c_u-5Ze5APvEYEhruSov7iF?usp=drive_link>
- Annotated with bounding boxes and exported in YOLO format

## Tools
- Python
- Ultralytics (YOLO)
- Ollama (Llama 3.2 1B)

## Folder Structure
- raw_images/: original photos
- annotated/: images and YOLO labels
- exports/: final dataset
